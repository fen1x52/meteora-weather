# Проверка поставки

Этот файл фиксирует проведённые проверки, а не обещает постоянную доступность внешних API.

## Автоматические проверки

Финальные результаты строгой проверки TypeScript, ESLint, unit-тестов и production-сборки будут записаны после завершения реализации. До этого момента считать их пройденными нельзя.

## Реальные API

Выполнено `node scripts/smoke-api.mjs` 5 ноября 2026 года, 18:36:25 UTC (22:36:25 Europe/Samara). Все девять запросов вернули HTTP 200, ожидаемую форму JSON и `Access-Control-Allow-Origin: *`.

| Проверка | Результат |
| --- | --- |
| Open-Meteo Forecast | 14 дневных значений, почасовой ряд, текущие условия, единицы °C и м/с |
| Open-Meteo Geocoding | Результаты поиска с числовыми координатами |
| Open-Meteo Air / CAMS | Текущее время и почасовой ряд |
| Open-Meteo Historical | Три дня исторического реанализа |
| USGS | GeoJSON FeatureCollection |
| NASA EONET | Массив событий |
| NOAA SWPC | Непустая таблица планетарного Kp |
| RainViewer | Хост тайлов и прошедшие радарные кадры |
| NOAA NWS | Коллекция официальных предупреждений для точки в Нью-Йорке |

Запросы выполнялись из Node.js; проверка заголовка CORS не равнозначна полноценному браузерному сценарию. Успешный запуск не гарантирует будущую доступность сервиса. Примеры погодных значений не сохранялись и не подставлялись в приложение.

## Ручная проверка

Проверка браузером и адаптивности выполняется после запуска приложения. Если доступный инструмент не позволяет проверить сценарий, это будет явно указано здесь.
